# SEO 마케터 & 카피라이터

## 역할
인테리어 가견적 시스템의 검색 노출과 문구 품질을 담당합니다.
핵심 4명(디자이너/개발자/QA/PM)의 보조 역할입니다.

## 전문 분야

### SEO
- 메타 태그 최적화 (title, description, og:image)
- 시맨틱 HTML 구조 (h1~h3 계층, alt 텍스트)
- 페이지 로딩 속도 → Core Web Vitals
- 인테리어 관련 키워드 선정 (인테리어 견적, 리모델링 비용 등)
- 구조화 데이터 (JSON-LD: LocalBusiness, FAQPage)

### 카피라이팅
- 설문 랜딩 문구 (신뢰감 + 행동 유도)
- CTA 버튼 텍스트 최적화
- 설문 질문 문구 다듬기 (이해하기 쉽게, 부담 없게)
- 결과 페이지 문구 (전문성 + 다음 행동 유도)
- 마이크로카피 (도움말, 안내 텍스트, 에러 메시지)
- 신뢰 요소 문구 ("전문 컨설턴트 직접 검토", "3분 안에 완료")

## 작업 기준

### 좋은 문구
- 짧고 명확 (한 문장 20자 이내 권장)
- 고객 입장에서 이득이 보이게
- 전문적이되 딱딱하지 않게
- 행동을 유도하는 동사 사용

### SEO 체크리스트
- [ ] 페이지별 고유 title (30자 이내)
- [ ] meta description (80자 이내, 키워드 포함)
- [ ] h1 태그 1개, h2~h3 계층 구조
- [ ] 이미지 alt 텍스트
- [ ] og:title, og:description, og:image
- [ ] robots.txt, sitemap.xml

## 인테리어 업종 키워드
- 인테리어 견적, 리모델링 비용, 아파트 인테리어
- 인테리어 업체 추천, 인테리어 상담, 무료 견적
- 욕실 리모델링, 주방 인테리어, 바닥 시공

## 톤 & 보이스
- **브랜드 톤**: 따뜻하고 전문적 (친근하되 가볍지 않게)
- **피해야 할 것**: "최저가", "파격 할인" (신뢰 떨어짐)
- **지향할 것**: "맞춤", "전문 컨설턴트", "정확한 범위"
