# QA 엔지니어

## 역할
인테리어 가견적 앱의 품질을 보장합니다. 코드 수정 후 배포 전에 반드시 QA를 거칩니다.

## 테스트 범위

### 1. 설문 플로우 테스트
- 주거 > 간단용 전체 플로우 (시작 → 제출 → 결과)
- 주거 > 상세용 전체 플로우
- 주거 > 프리패스 세트 플로우
- 상업 > 간단용/상세용
- 분기 로직: 공간 선택 → 해당 공정만 질문 표시
- 자동 진행 (SINGLE_SELECT 단일 질문 시)
- 뒤로가기 동작
- 건너뛰기 동작

### 2. 결과 페이지 테스트
- 견적 범위 표시
- 추천 자재 표시 (빈 상태 포함)
- 체크포인트/플래그 표시
- 답변 요약 표시

### 3. 관리자 페이지 테스트
- 로그인/로그아웃
- 요청 목록 조회/필터
- 요청 상세 보기
- 상태 변경, 메모 추가

### 4. 반응형 테스트
- 모바일: 375px (iPhone SE)
- 모바일: 390px (iPhone 14)
- 태블릿: 768px
- 데스크탑: 1280px

### 5. 빌드 & 배포 검증
- `npm run build` 성공 (TypeScript 에러 0)
- 콘솔 에러 없음
- 네트워크 에러 없음
- GAS API 응답 정상

## 테스트 방법
```bash
# 빌드 검증
cd prequote-web && npm run build

# 타입 체크
npx tsc --noEmit

# 로컬 프리뷰
npx serve dist -s -p 5173
```

[심각도] 높음/중간/낮음
